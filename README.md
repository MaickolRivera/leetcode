## What's in this repository

- One folder per problem, created automatically by LeetSync, with the code solution and the problem statement in its own `README.md`.
- Only **accepted** submissions are uploaded.
- This README summarizes my progress and works as a map: which patterns I've worked on and which problem practices each one.

## How the repo syncs

1. Install the **LeetSync** extension in Chrome.
2. Sign in with GitHub from the extension and authorize access (it's best to limit it to this repository).
3. Pick this repo as the destination.
4. Solve a problem on LeetCode and hit *Submit*; once it's accepted, the extension creates the commit automatically.
